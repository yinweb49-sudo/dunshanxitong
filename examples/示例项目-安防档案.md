> 盾山系统的已填示例。由参考项目的真实档案脱敏改写：项目名、产品名、代码文件名、内部路径、证书信息和人员都已替换，只用来演示档案的填法和体检输出的格式。
> 依据：攻击交接包、项目代码（逐项核到文件）、需求文档、运维文档、本地生产快照库只读核对。
> 不含服务器地址、数据库地址、任何密钥。项目里正式使用时放到 `docs/安防档案.md`。

## 0. 定档

| 项 | 内容 |
|---|---|
| 档位 | 三档 正常 |

## 1. 基本信息

| 项 | 内容 |
|---|---|
| 技术栈 | .NET 10 单体后端；React + Vite 三个前端（官网与会员中心、员工 ERP、代理后台）；SQL Server |
| 部署 | 云服务器 Windows Server + IIS（进程内托管），一台应用服务器挂四个站点 |
| 服务器前面有没有代理 | **无，直连**（访问日志里服务端是内网地址、客户端是真实公网地址）。所以取 IP 只认连接地址；将来加 CDN 必须同步改 |

## 4. 十四道盾结论

### 已做（按盾分）

**1 主机与网络**
- 封 IP：Windows 防火墙三个配置文件全关，改用 IPsec 静态策略，已封 3 个攻击 IP，策略服务设为自动启动。
- IIS 动态 IP 限制已装（10 秒 300 次，代理模式关，只按频率）。
- SSH 只用密钥，授权文件权限只留管理员和系统；运维文档不存密码。
- 旧官网站点在我方服务器上保持停用。

**2 来源与限速**
- 全站唯一取 IP 方法，只认连接地址；11-01 后修掉了 9 个各自读转发头的文件；有伪造头测试。
- 第 3 节全部匿名接口有限速。

**3 登录与会话**
- 统一失败话术、固定耗时（员工端账号不存在时跑一次假 Argon2）。
- 员工后台陌生设备验证（扫码优先、自动转短信、静默绑定、不换绑、设备凭证只存哈希、可踢设备、可看登录记录、超管汇总）。
- 三套 Cookie：HttpOnly、SameSite=Lax、分端命名；员工端每请求校验禁用、审批状态、版本号、强制改密；代理端每请求校验代理是否有效。
- 会话加密密钥持久化在发布目录之外。
- 所有签发会员登录态的入口（12 处）共用"能不能登录"判断，含攻击号特征拦截。
- 员工、代理渠道账号密码 Argon2id。

**4 注册找回与验证码**
- 注册、找回必须服务端核销短信验证码（1.6 万次注册一个没成功）。
- 图形验证码改为字形轮廓，源码里没有答案，有测试。
- 用户名拒绝控制字符、空白、零宽字符（会员与员工注册共用），有测试。
- 找回密码两种失败同一句提示。

**5 输入与输出**
- 全站参数化（攻击载荷全部被原样存为文字）。
- 三套服务端 HTML 清洗器（文章教程、服务详情、AI 模板），模板渲染页严格 CSP（禁脚本）+ 令牌访问。
- 外部原文在后台用无权限沙箱 iframe 预览。
- 生产不出业务 sourcemap；前端无密钥；登录态不在 localStorage。
- 所有 `/api` 响应 no-store；未匹配的 `/api` 路径一律 404；生产不返回堆栈。
- 登录回跳只允许站内路径。

**6 文件**
- 上传存储名系统生成（GUID / 内容哈希），按场景限类型和大小，多数场景按文件头或实际解码校验。
- 对象存储直传把类型和大小写进签名。
- 工单附件不挂静态路由，四道校验后下载，带 nosniff，默认附件形式。
- 代上架客户资料走私有对象存储 + 服务端签名取回；打包下载只保留纯文件名（11-01 修）。

**7 出站**
- 抓取图片、按网址取图、Webhook 推送：在连接时按解析出的 IP 拦内网，能防 DNS 重绑定；限重定向、超时、限大小。

**8 资金与回调**
- 后端计价；支付回调验签、AEAD 解密、报文与金额严格核对、通知 ID 防重放、交易号范围锁 + 订单行锁 + 状态机幂等、唯一索引兜底，五条到账支路都走同一套核对。
- 公众号回调安全模式 + 常数时间验签；OAuth state 一次性 + 浏览器绑定 Cookie。
- 退款只走存储过程，按时效分级授权。

**9 权限与审计**
- 角色 + 权限点，194 个权限码、698 处接口级声明，拒绝时单独审计。
- 418 处审计声明（112 处高风险，存前后快照），审计只读。
- 会员、代理接口身份只从登录态取，抽查均带归属过滤，未发现越权。
- 开发 / 模拟到账接口只在本地开发注册。

**10 密钥与敏感数据**
- 本地 user-secrets；生产配置、密钥目录、证书、备份、发布包被 .gitignore 挡住，历史里也没有。
- 签名私钥、渲染令牌放服务器环境变量，不进包。
- 店铺凭证 AES-256-GCM；没配密钥拒收。
- 配置页密钥只显示"已配置"；API 密钥只存哈希、只显示一次。
- 手机号、IP、OpenID、设备码、联系方式按权限脱敏。

**11 生产与发版**
- 本地默认连生产快照测试库；只读核对模式三层保护。
- 迁移执行器：文件名与目录限制、打印目标库、识别生产库需 `-AllowProd`。
- 大改动前 bacpac 备份。
- 发版：正式包配置闸门、剔开发配置与密钥目录、删除护栏、上传回读大小、停池改名解压、失败自愈回滚、保留旧版、发版台账。
- Gitea 只走私网，凭据在系统凭据管理器。

**12 监测与应急**
- 限速、锁定、冷静期触发写警告日志。
- 11-01 应急全流程留档（交接包、证据、删号备份、处置报告）。

**13 AI 功能**
- AI 生成的图文模板走最严的白名单清洗器，渲染页禁脚本 CSP + 令牌访问。
- 客服聊天截图交给模型前，前后端各做一次联系方式脱敏。
- 平台 AI 密钥在服务端（但客户端网关拼在上游 URL 里、且免费档无额度，见待办 7、32）。

**14 研发链路**
- 三个前端锁文件入库；Gitea 只走私网；生产配置、密钥目录、证书、备份被 .gitignore 挡住，历史里也没有。
- 生产库迁移执行器有生产护栏；本地有生产只读核对模式。
