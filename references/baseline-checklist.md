# 十四道盾逐项清单

体检和开工布防都按这张表走。先按 `tiers.md` 定档，再只看适用的项。

- **档位**：从哪一档起必做。保 = 一档保底起所有项目；基 = 二档基础起；正 = 三档正常起；极 = 只有四档极度。
- **级别**：适用后多急。**P0** 上线前必须；**P1** 上线后一个月内；**P2** 有余力时做。
- 标【专项】的分组或条目只在项目有对应功能时适用，适用后同样按档位列执行。

每个适用项在项目安防档案里给结论：已做（证据）/ 不适用（原因）/ 待做（优先级）。高于本项目档位的项统一记"档位外"，不必逐条写原因。
